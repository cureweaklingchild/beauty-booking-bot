# Бот записи к мастерам

Первая версия Telegram-бота на `aiogram 3` и SQLite.

## Запуск на Windows

1. Установите Python 3.11 или новее с сайта https://www.python.org/downloads/.
2. Откройте терминал VS Code в этой папке.
3. Создайте виртуальное окружение:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
```

Если PowerShell запретит активацию, выполните один раз от имени текущего пользователя:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

4. Установите библиотеки:

```powershell
py -m pip install -r requirements.txt
```

5. Создайте копию `.env.example` с именем `.env`.
6. Получите токен у Telegram-бота `@BotFather` командой `/newbot` и вставьте его в `.env`.
7. Напишите боту `/id`, скопируйте свой числовой Telegram ID и добавьте его в `ADMIN_IDS`.
8. Запустите:

```powershell
py bot.py
```

## Как пользоваться

Мастер: открыть `/start` -> `Кабинет мастера` -> указать имя. В разделе `Мои услуги` можно добавить название услуги, длительность и цену. При добавлении свободного окна мастер выбирает, для какой услуги это время. В разделе `Мои записи` мастер может отменить запись, клиент получит уведомление.

Клиент: открыть `/start` -> `Записаться` -> выбрать мастера -> выбрать услугу -> выбрать свободное время.

Клиент также может открыть `Мои записи`, посмотреть будущие записи и отменить нужную запись. После отмены окно снова становится свободным, а мастер получает уведомление.

После записи мастер получает сообщение, а все данные сохраняются в `booking.sqlite3`.

## Mini App для мастера

В проект добавлен удобный календарь мастера. В нём можно:

- переключать месяцы и выбирать день;
- видеть свободные и занятые окна;
- добавлять несколько времён за один раз;
- выбирать услугу для окна;
- удалять свободное окно;
- добавлять услуги;
- получать проверку пересечений с учётом длительности услуги.

Для кнопки `Открыть календарь` нужен публичный HTTPS-адрес приложения. Укажите его в `.env`:

```env
MINI_APP_URL=https://ваш-домен.example
WEBAPP_PORT=8000
```

Сервер Mini App запускается вместе с `py bot.py`. Для локальной проверки можно открыть сервер на порту 8000, но Telegram не откроет Mini App по обычному `http://localhost`: нужен HTTPS-адрес, например через хостинг или временный туннель.
